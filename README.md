# 関東運行情報ボード

ODPT（公共交通オープンデータセンター）のデータを使って、関東の鉄道のリアルタイム運行状況を表示するシンプルなWebページ。サーバー不要、完全無料で公開できる。

## ファイル構成

- `index.html` — ページの骨組み
- `style.css` — 駅の発車標(電光掲示板)っぽいデザイン
- `config.js` — APIキーと表示する路線のリスト（ここをいじって路線を増やす）
- `script.js` — ODPTのAPIを叩いてデータを表示する処理

## セットアップ手順

### 1. ODPTのAPIキーを取得する

1. https://developer-dc.odpt.org/ から開発者登録（無料）
2. 登録が承認されたらAPIキーが発行される（数営業日かかることがある）
3. `config.js` の `YOUR_API_KEY_HERE` を発行されたキーに置き換える

### 2. ローカルで試す

`index.html` をブラウザで直接開くだけでOK（ただしブラウザによってはローカルファイルの `fetch` がブロックされることがあるので、その場合は下記のどちらかを使う）

```bash
# Pythonが入っていれば
python3 -m http.server 8000
# → http://localhost:8000 を開く
```

VS Codeなら「Live Server」拡張機能を入れるのが手軽。

### 3. 路線を追加する

`config.js` の `LINES` 配列に、路線名・ODPTの路線ID・色を追加するだけ。路線IDはODPTのAPI仕様ページかカタログサイトで調べられる。

### 4. GitHub Pagesで無料公開

1. GitHubで新しいリポジトリを作る
2. このフォルダの中身をpush
3. リポジトリの Settings → Pages で公開ブランチを設定
4. `https://ユーザー名.github.io/リポジトリ名/` でアクセスできるようになる

## 注意点（つまずきやすいところ）

- **CORSエラーが出る場合**: ブラウザから直接ODPTのAPIを叩くとブロックされることがある。その場合は無料の Cloudflare Workers などでAPIキーを隠しつつ中継する小さなプロキシを挟むのが定番の回避策（必要になったらまた聞いて）。
- **APIキーが公開される**: このままGitHub Pagesに置くと `config.js` の中身は誰でも見える。個人の学習・検証用途なら大きな問題になりにくいが、気になるなら上記のプロキシ経由にするとキーを隠せる。
